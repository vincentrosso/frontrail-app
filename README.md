# Front Rail (iPhone shell)

A thin iPhone app that loads https://frontrail.ndex.us. All logic lives in the web page, so a web deploy updates the app with no store release. The site, the scoring engine and the notes live in a separate private repo.

- `ios/` — SwiftUI + WKWebView shell, bundle id `us.ndex.frontrail`. The Xcode project is generated by `xcodegen` from `ios/project.yml`.
- `.github/workflows/ios.yml` — unsigned simulator build on every change to `ios/`.
- `.github/workflows/ios-release.yml` — signed build uploaded to App Store Connect (TestFlight). Run by hand. Signing material lives in repo secrets, never in this repo.

This repo is public only so GitHub's macOS build minutes are free. It holds no keys, codes or personal details; keep it that way.
